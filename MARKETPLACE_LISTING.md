# Marketplace listing draft for ResQconnect / Aegis Treasury

Short description:
Aegis Treasury by ResQconnect — Hybrid post-quantum cryptography platform for secure key storage, transaction signing, and enterprise-grade data protection. Available as SaaS or self-hosted with per-seat licensing.

Long description (draft):
Aegis Treasury provides a hybrid post-quantum cryptography stack combining traditional elliptic-curve primitives with post-quantum algorithms for future-proof data protection. ResQconnect's solution helps students, small businesses, IT and cybersecurity teams, and enterprises keep private keys, sensitive data, and transactions secure.

Key features:
- SaaS or self-hosted deployment
- Self-hosted license tokens (signed JWTs) for offline validation
- HSM/KMS backing for custodial key storage
- Role-based access controls and audit logging
- Marketplace provisioning: seamless subscription handling via GitHub Marketplace webhooks
- Developer-friendly APIs and SDKs

Pricing tiers (suggestion):

- Starter: up to X users, basic support
- Professional: up to Y users, priority support, audit logs
- Enterprise: custom pricing, dedicated support, on-prem deployment assistance

Trial policy:
